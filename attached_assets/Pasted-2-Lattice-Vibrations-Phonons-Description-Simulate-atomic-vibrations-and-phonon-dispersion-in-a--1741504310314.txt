2. Lattice Vibrations (Phonons)

Description: Simulate atomic vibrations and phonon dispersion in a crystal.
Interactivity:
Choose 1D chain or 3D lattice (e.g., NaCl structure).
Adjust temperature (0–1000 K) and atomic mass (e.g., 1–100 amu).
Select phonon mode (longitudinal/transverse).
Visualization:
Animate 3D lattice vibrations with exaggerated displacements.
Plot 3D phonon dispersion curves (frequency vs. wavevector) in real-time.
Overlay density of states (DOS) graph.

Additional Features

UI Layout:
Sidebar: Select simulation (e.g., “Band Structure”).
Main Panel: 3D visualization + control sliders.
Bottom Panel: Graphs (e.g., DOS, dispersion) and equations.
Modes:
Basic (UG): Simplified controls, focus on visualization.
Advanced (MSc): Access to raw parameters (e.g., Hamiltonian terms) and derivations.
Educational Tools:
“Explain” button: Pop-up with concept summary (e.g., “What is a phonon?”).
Quiz Mode: “Calculate bandgap for Si at 300 K” with simulation data.
Derivation Viewer: Step-by-step math (e.g., Bloch theorem).
Export:
Save 3D animations as GIFs or band plots as PNGs.
Technical Implementation

Graphics:
Use Three.js (web) or OpenGL (desktop) for 3D rendering.
Optimize for smooth animation (e.g., 60 FPS on mid-range PCs).
Calculations:
Python (NumPy/SciPy) for phonon/band structure solvers.
Precompute heavy simulations (e.g., 3D DOS) for real-time display.
Validation:
Cross-check with textbook values (e.g., Si bandgap ≈ 1.12 eV).
Sample User Interaction

User selects “Band Structure” → chooses Silicon.
Adjusts lattice constant → 3D band plot updates, showing indirect bandgap.
Clicks “Animate Wavefunction” → sees electron probability density in 3D.
Takes quiz: “Why is Si an indirect bandgap material?” → Refers to simulation.
